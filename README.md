# Лабораторная работа №1 Программирование на языке Python
### Вариант M3 — Ввод в RPN (Обратная польская нотация)

### Цель работы:
#### Разработка калькулятора, в котором пользователь вводит выражение в обратной польской нотации(RPN)
- Вычислять математическое выражение в RPN
- Преобразовывать постфиксную запись в инфиксную запись для удобства проверки составления выражения
- Поддерживать различные математические операции, функции и константы
- Обрабатывать ошибки и исключения

### Библиотеки:
  - `math` - математические функции(sin,cos,sqrt и т.д)
  - `operator` - операторы сложения, вычитания, умножения и деления
  - `unittest` - тесты функциональности кода
