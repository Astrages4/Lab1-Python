# Лабораторная работа №1 Программирование на языке Python

### Вариант M3 — Ввод в RPN (Обратная польская нотация)

### Цель работы:

#### Разработка калькулятора, в котором пользователь вводит выражение в обратной польской нотации(RPN). Калькулятор позволяет:

- Вычислять математическое выражение в RPN
- Преобразовывать постфиксную запись в инфиксную запись для удобства проверки составления выражения
- Поддерживать различные математические операции, функции и константы
- Обрабатывать ошибки и исключения

### Библиотеки:

  - `math` - математические функции(sin,cos,sqrt и т.д)
  - `operator` - операторы сложения, вычитания, умножения и деления
  - `unittest` - тесты функциональности кода

### Допущения:

- Поддерживаются только положительные целые и дробные числа
- Поддерживаются базовые арифметические операции: `+`,`-`,`*`,`/`,`^`,`%`
- Поддерживаются математические функции: `sin`, `cos`, `tan`, `sqrt`, `log`, `ln`, `exp`(возведение `e` в степень), `abs`(модуль), `floor`(округление числа в меньшую сторону до ближайшего целого числа), `ceil`(округление числа в большую сторону до ближайшего целого числа)
- Поддерживаются математические константы: `pi`, `e`
- Преобразование RPN-выражения в инфиксное выражение
  
### Ограничения:

- Не поддерживаются отрицательные числа на вводе
- Не поддерживается возведение в отрицательные степени
- Не поддерживаются пользовательские переменные

### Ошибки, обрабатываемые кодом:

- Деление на ноль
- Неизвестные операторы и функции
- Недостаточное количество операндов
- Ошибка токенизации
- Некорректный формат чисел
- Некорректные символы в выражении
- Отрицательная степень не поддерживается
- Квадратный корень из отрицательного числа не берётся

### Алгоритм работы(кратко):

#### Читаем токены слева направо, числа(токены) кладём в стек, операторы извлекают
аргументы из стека и кладут результат обратно.

### Алгоритм работы(подробно):

#### 1. Токенизация( `tokenize(self, expression)` )
    - Входная строка разбивается на отдельные токены, добавляется в стек
    - Распознаются числа, операторы, функции и константы
    - Строковые представления чисел преобразуются в числовые типы
    - Валидируется корректность токенов
    
#### 2. Преобразование в инфиксную запись( `rpn_to_infix(self, rpn_tekens)` )
    - Запись в RPN преобразуется в привычную нам математическую запись вида `(число)(оператор)(число)`
    - Скобки расставляются автоматически согласно приоритетам операторов
    - Обрабатывает унарные и бинарные операции
    
#### 3. Определение приоритета оператора в выражении( `_get_operator_precedence` )
    - Если выражение в скобках - внешние скобки убираются. Проверяется сбалансированность скобок( если есть `(`, то в счётчик скобок(`bracket_count`) добавляем 1, если есть `)`, то из счётчика скобок(`bracket_count`) вычитаем 1. Если `bracket_count` равен 0, то всё нормально)
    - Ищется оператор с наименьшим приоритетом(не в скобках)
    - Проходим стек с конца для правильного определения ассоциативности

#### 4. Вычисление( `evaluate_rpn(self, rpn_tokens)` )
    - C помощью стека вычисляется выражение
    - Операции обрабатываются в правильном порядке
    - Выполняется математическая функция(вычисление)
    - Если есть любая ошибка - выводит ошибку

#### 5. Ввод, вывод и подобие интерактивного режима( `calculate(self, expression)` )

##### При запуске кода автоматически выводится аннотация к калькулятору:
    Калькулятор обратной польской нотации (RPN)
    Доступные команды: help, exit
    Введите выражение в RPN формате (например: '3 4 + 2 *')

###### При вводе `help` выводится:
    Доступные операторы: +, -, *, /, ^, %
    Доступные функции: sin, cos, tan, sqrt, log, ln, exp, abs, floor, ceil
    Константы: pi, e
    Пример: 3 4 + 2 * => (3 + 4) * 2 = 14

###### При вводе `exit` выводится:
    До свидания!

##### Ввод происходит в формате:
    RPN> (выражение в RPN-формате)
##### Вывод происходит в формате:
    Токены RPN: [токен, токен, токен...]
    Инфиксная запись: выражение
    Результат: результат вычисления

#### Пример:
    RPN> 3 ln 
    Токены RPN: [3, 'ln']
    Инфиксная запись: ln(3)
    Результат: 1.0986122886681098
